# CloudPrism

CloudPrism is an Auto-orchestrated, multi-tenancy enabled Data Guardian, encrypting Smart Protocol, through a Centralized Manager and secure Gateway.

With CloudPrism, you get a lightweight tool that stays out of your way.

**What you get**

- CloudPrism is an Auto-orchestrated, multi-tenancy
- enabled Data Guardian, encrypting Smart
- Protocol, through a Centralized Manager

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/CloudPrism.git`
2. `cd CloudPrism`
3. Install in editable mode: `pip install -e .`

## Configuration

Runtime options can be set in the config file or overridden per call. The most commonly changed values are:
- **timeout**: how long operations may run before failing
- **retries**: how many times a failed operation is re-attempted
- **cache**: where temporary results are stored
